## 版本 2.0.0 (2026-10-14) —— 后端重构版

### 功能
- 新增 `GET /api/health` 健康检查接口
- 补齐 17 个前端调用但后端缺失的接口，包括：
  - 管理后台：数据库信息/表清单/备份/优化/设置/通知列表/通知统计/举报消息/私聊概览/群聊概览
  - 用户侧：撤回消息/清空会话/举报消息/转发消息/搜索消息/好友申请/好友列表/通知/文件上传/头像上传/创建目录
- 新增博饼式拼手气红包的份额预分配机制
- 新增 `scripts/test_api.py` 接口回归测试脚本（76 项）
- 新增 `scripts/migrate_db.py` 幂等数据库迁移脚本

### 改进
- **架构重构**：从单文件 `run.py` 改为应用工厂 + 蓝图分层架构（`app/` 包），
  拆分为 config/database/validators/security/responses/errors/logging/socket_events 八个基础模块
- **安全加固**：
  - 密钥不再硬编码，支持环境变量/配置文件/自动生成三级解析
  - 新增登录失败锁定与全接口限速
  - 新增完整输入校验（密码强度、用户名格式、各字段长度）
  - 管理后台口令改为 bcrypt 哈希 + 常量时间比对
  - WebSocket 发送者改为服务端判定，不再信任客户端
  - CORS 改为白名单，默认不启用跨域
  - 文件上传增加扩展名白名单与文件名重写
- **健壮性**：
  - 统一错误处理，所有 API 异常返回结构化 JSON
  - 统一响应格式 `{success, message, data}`
  - 统一数据访问层，启用 WAL 与连接复用
  - 断线在线状态清理改用 sid 映射（修复永久在线缺陷）
  - 管理后台接口从硬编码假数据改为真实数据库查询
  - 通知接口从 TODO 未实现改为真实投递 + WebSocket 推送
  - 日志改为可配置的轮转策略
- **业务正确性**：
  - 坤币余额变动全部置于单事务，扣款使用条件更新，杜绝并发双花与负余额
  - 红包金额分配算法重写，保证每份 ≥1 且总和精确
  - 修复并发抢红包竞态（同一用户并发请求可抢到多份）
- 移除废弃依赖 `pathlib==1.0.1` 与未使用的 `eventlet`
- 新增 `.gitignore`，数据库/日志/备份/上传/密钥不再入版本库

### 修复
- **修复 `/admin` 与 `/admin/dashboard` 返回 500**（模板路径错误）
- **修复 `limit=abc` 等非法参数触发 500**（现返回 400）
- **修复可注册 1 字符密码与超长用户名**（现校验强度与长度）
- **修复可写入 100000 字符昵称**（现限制 32 字符）
- **修复 `/api/chat/history` 不认 `chat_id` 参数**（前端调用必然 400）
- 修复裸 `except:` 吞掉所有异常，现明确区分令牌过期与非法
- 修复 `finally` 中 `if conn:` 在连接失败时抛 `NameError`
- 修复断线用户在线状态不清理，导致永久显示在线
- 修复管理后台统计/用户/群组/日志返回假数据、删除用户不真删
- 修复系统通知只写日志从不投递到用户
- 修复 README 接口路径与实际路由不符
